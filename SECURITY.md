# Security Policy

Please do not report security issues through public GitHub issues.

GitHub private vulnerability reporting is currently not enabled for this repository. Submit a private support ticket through [Waveshare's official support service](https://service.waveshare.com/) for vulnerability reports, and include enough detail to reproduce and assess the issue.

For non-security bugs, use the regular GitHub issue template.

---

# 安全策略

请勿通过公开的 GitHub issue 报告安全问题。

本仓库当前未启用 GitHub 私密漏洞报告。请通过 [Waveshare 官方支持服务](https://service.waveshare.com/)提交私密工单来报告漏洞，并提供足够的信息，以便复现和评估问题。

非安全类缺陷请使用常规 GitHub issue 模板。
