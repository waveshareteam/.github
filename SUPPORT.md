# Support

For product usage questions, hardware support, or order-specific help, contact Waveshare through the official support channels and include the product name and order information when applicable.

For repository issues, open a GitHub issue with:

- the example path
- the framework and version
- steps to reproduce
- expected behavior
- actual behavior
- relevant logs or screenshots

---

# 支持

如需产品使用、硬件或订单相关支持，请通过 Waveshare 官方支持渠道联系，并在适用时提供产品名称和订单信息。

对于仓库问题，请创建 GitHub issue，并提供：

- 示例路径
- 框架及版本
- 复现步骤
- 预期行为
- 实际行为
- 相关日志或截图
